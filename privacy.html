Privacy Policy

Effective: October 1, 2026

Louis Owner Mail is a private, single-owner integration. It accesses Google user data only to provide owner-requested Gmail reading, review, drafting, and sending functions.

Google data accessed

The integration uses Gmail read-only access to retrieve messages and Gmail send access to transmit an exact owner-approved draft. It requests basic account identity information only to verify that OAuth authorization belongs to the configured Louis Gmail account.

Use and storage

Message content is processed locally on the owner’s Mac and may be stored in an owner-only local review queue. OAuth credentials are stored in owner-only local files. Google user data is not used for advertising, profiling, or training public models.

Sharing and sale

Google user data is not sold, rented, shared with data brokers, or disclosed to third parties. Data is transmitted to Google only as needed to use the Gmail API and deliver an owner-approved message.

Retention and deletion

The owner controls local records and may delete them or revoke Google access at any time. Revoking access prevents future Gmail API access.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
